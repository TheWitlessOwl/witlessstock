HOW TO INSTALL THIS AS AN APP ON YOUR PHONE
=============================================

Step 1: Create a free GitHub account (skip if you have one)
-------------------------------------------------------------
Go to https://github.com/signup and sign up (just an email + password).

Step 2: Create a new repository
-------------------------------------------------------------
1. Click the "+" icon (top right) -> "New repository".
2. Name it something like "stock-tracker".
3. Set it to "Public".
4. Click "Create repository".

Step 3: Upload these files
-------------------------------------------------------------
1. On your new repository page, click "uploading an existing file"
   (or Add file -> Upload files).
2. Drag in all 5 files from this folder:
   - index.html
   - manifest.json
   - sw.js
   - icon-192.png
   - icon-512.png
3. Click "Commit changes".

Step 4: Turn on GitHub Pages
-------------------------------------------------------------
1. In your repository, click "Settings" (top menu).
2. Click "Pages" in the left sidebar.
3. Under "Branch", choose "main" and folder "/ (root)", then Save.
4. Wait about a minute, then refresh the page. GitHub will show you a
   web address, something like:
   https://YOUR-USERNAME.github.io/stock-tracker/

Step 5: Install it on your phone
-------------------------------------------------------------
1. Open that address in Chrome on your Android phone (or Safari on iPhone).
2. Android/Chrome: tap the 3-dot menu -> "Add to Home screen" or "Install app".
   iPhone/Safari: tap the Share icon -> "Add to Home Screen".
3. Open it from the icon on your home screen. It will run full-screen,
   like a normal app, and the camera scanner will work properly since
   it's no longer inside a frame.

Your data is stored in the browser on your phone. Use the Backup button
inside the app regularly to save a copy, since clearing your browser data
would clear the app's data too.

WANT A REAL .APK FILE INSTEAD?
-------------------------------------------------------------
Once the site is live at your github.io address:
1. Go to https://www.pwabuilder.com
2. Paste in your github.io link and click "Start".
3. Click the "Android" package option and follow the prompts to
   download a signed APK you can sideload onto your phone.
